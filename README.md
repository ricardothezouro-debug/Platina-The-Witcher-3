# The Witcher 3: Wild Hunt, guia de platina

Guia em português do Brasil para obter a platina do jogo base no PlayStation 5,
na versão Remastered, em uma única campanha na dificuldade Marcha da Morte.

O guia preserva a exploração livre. Em vez de impor um passo a passo, ele usa
regiões, progresso da história marcado pelo jogador e portões de segurança antes
dos pontos que podem fechar missões, cartas ou troféus.

## Estado atual

Esta versão reúne 53 troféus, 25 contratos do jogo base, alertas antes dos
pontos sem volta e uma auditoria de Gwent por missão, região e 18 pontos de
venda. O painel Agora prioriza os alertas, e as caixas podem ser marcadas ou
desmarcadas. As abas Regiões e Gwent incluem diagramas locais; uma ilustração
local aparece quando a arte oficial não puder ser carregada. A equivalência
exata de todos os gatilhos com o Remastered ainda depende de teste no PS5.

O ícone do catálogo é uma arte original gerada para este projeto. Ele não usa o
medalhão ou o logotipo oficial do jogo.

## Rodar sozinho

No Windows:

```text
set PYTHONPATH=src
python -m platina_witcher3
```

No macOS ou Linux:

```text
PYTHONPATH=src python -m platina_witcher3
```

O progresso fica na pasta de dados do Streamer Sidekick e não dentro do plugin.
